# Iteración 0.5 — catálogo ejecutable y fijado por mundo

Reglas 4, checkpoint 3, paquete base 2.0.0. El esquema completo World2 y los sistemas históricos siguen pendientes.

El mundo conserva definiciones inmutables de edificios y tecnologías. Vista previa, órdenes, duración de obra y producción consultan esas definiciones; los checkpoints las comparan con los paquetes exactos. Una discrepancia se rechaza antes de publicar o sustituir una sesión. Los ejecutores 1–3 conservan sus tablas congeladas.

Las capacidades tecnológicas declaradas gobiernan los mecanismos admitidos. Se eliminó la bonificación genérica por contar tecnologías en reglas 4. Vivienda y defensa usan los valores declarados. Generadores y talleres consumen entradas declaradas según actividad efectiva; sin personal o suministros no producen, y un suministro parcial limita proporcionalmente el resultado.

El paquete base 2 y el ejemplo 2 tienen versiones y hashes nuevos. Los mundos existentes continúan con sus bytes de contenido originales. Se incluye el archivo base 1 exacto para migrar contenedores del prototipo; el resolvedor exige su SHA-256 y conserva la copia original. No se sustituye por contenido instalado más reciente.

## Evidencia

- Batería completa: 108 pruebas Flutter aprobadas y análisis limpio.
- Pruebas de comportamiento: cambiar costes, duración, rendimiento, capacidades tecnológicas y vivienda altera el mundo; contenido cambiado tras fijarlo se rechaza; entradas insuficientes limitan la producción; ejecutor antiguo y recuperación con contenido archivado permanecen operativos.
- Equivalencia: 36.000 días, décadas, siglo y guardado irregular, con catálogo real y 38.451 entradas causales completas idénticas.
- APK profile compilado, paquete y firma de pruebas inspeccionados; hashes y registros en `results.json`.
- Instalación y funcionamiento Android se registran aparte cuando concluyen. La evidencia Android de trabajo/transporte 0.4 no se presenta como ejecución de este binario.

## Límites

El catálogo no admite operaciones arbitrarias: rechaza funciones no implementadas. Los 30 conocimientos existentes conservan los mecanismos admitidos; faltan alternativas históricas, pérdida de capacidades y los objetivos ampliados de contenido. El presupuesto laboral sigue usando equipos de cuatro; el metadato antiguo de dos trabajadores se interpreta por el ejecutor compatible, no promete equipos configurables.

No se declara cerrado R2 ni R3: falta conciliación demográfica completa, libro global de todos los flujos, familias, instituciones y modelo final. Tampoco acredita prehistoria, seis eras, equinos, narrativa completa, milenio activo, rendimiento del teléfono de referencia o arte final.
